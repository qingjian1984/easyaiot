## 1. 目标

实现告警公共枚举、无副作用状态机和事件 Envelope 不变量，为后续持久化/API/消息切片提供单一编译合同。本任务不产生用户可见功能，也不启用任何告警 capability。

## 3. 实现约束

- Java 17，但保持现有模块可编译风格；不新增第三方依赖。
- 公共契约放 API，状态转换逻辑放 BIZ；禁止 API 依赖 BIZ。
- 状态机不读取数据库、Spring Context、TenantContext、当前时间或随机数。
- 结果明确表达 targetStatus、是否状态变化、忽略前状态和稳定错误码。
- `AlarmEventEnvelope` 使用不可变字段和防御性 payload；JSON 大小/Schema 严格校验留给后续 contract adapter。
- dotted 事件名必须与冻结记录完全一致。
- 不复制或修改 `PowerModelEventEnvelope`，避免两个领域耦合；可复用其验证方法思想。

## 4. 必测场景

1. SOURCE_RAISED 创建/重复 occurrence 的所有活动状态。
2. ACTIVE→ACK→PROCESSING→RECOVERED→CLOSED。
3. IGNORE/ACK/UNIGNORE/EXPIRE/RECOVER 组合及 ignoredFromStatus 缺失。
4. EMERGENCY 忽略稳定拒绝。
5. CLOSED/FALSE_ALARM 终态拒绝。
6. RECOVERED 同 cycle raise 冲突、重复 recover no-op。
7. 误报无 pending、同人复核、批准/拒绝路径。
8. ESCALATE 不改变主状态，IGNORED 不允许升级。
9. Event Envelope 正常与所有非法不变量、payload 防御复制。
