## 1. 目标

把 `alarm_action_log.sequence_no` 从 `alarm_record.row_version` 中解耦，使用告警主记录上的独立计数器和 PostgreSQL 单行原子 `UPDATE ... RETURNING` 分配动作序号，并以本地单元/静态合同证明来源发生、来源恢复、并发冲突、幂等重放和事务回滚不会产生重复或错误的已提交序号。

本任务只整改 P02-M2-02B 已实现的候选 DDL、持久化端口和来源事务编排，不执行 SQL、不连接数据库、不接入来源或物理 transport。

## 3. 冻结设计

### 3.1 数据字段

在候选 `alarm_record` 增加：

```sql
last_action_sequence BIGINT NOT NULL DEFAULT 0
    CHECK (last_action_sequence >= 0)
```

必须同步中文列注释，语义为“该告警已提交动作的最后序号；仅由原子分配器递增”。V011 仍是 review-only 候选资产；不得执行，不得加入默认 apply 链。U011 删除整表，不需要因新增列修改。

### 3.2 分配端口与 SQL

持久化端口新增单一用途方法，为指定 `tenantId/siteId/alarmId` 分配并返回下一动作序号。JDBC 实现必须使用以下等价的单语句原子更新：

```sql
UPDATE public.alarm_record
SET last_action_sequence = last_action_sequence + 1
WHERE tenant_id = :tenantId
  AND site_id = :siteId
  AND id = :alarmId
RETURNING last_action_sequence
```

返回 0 行必须 fail-closed 为稳定的目标不存在/数据范围错误，不得回退到 `MAX(sequence_no)+1`、`row_version + 常量`、全局 sequence 或进程内计数器。分配 SQL 不携带 `row_version` 条件；状态并发由状态 CAS 独立负责。

### 3.3 事务顺序

- 首次来源发生：Inbox 仲裁 → 创建主记录/映射 → 分配序号 1 → 追加 `SOURCE_RAISED` → Outbox → Inbox `PROCESSED`。
- 已有活动周期再次发生或恢复：Inbox 仲裁 → 状态/次数 CAS → 分配下一序号 → 追加动作 → Outbox → Inbox `PROCESSED`。
- 状态 CAS 返回 0：立即返回冲突或无操作，不调用分配器。
- 重复 Inbox/重复幂等请求：不调用分配器，不追加动作。
- 分配后任一步失败：整个事务回滚；计数器递增与动作/Outbox 一并撤销。

动作 ID、`request_id` 幂等唯一约束和 `sequence_no` 是三个独立概念，不得互相代替。未来人工状态、升级、忽略到期、维护/抑制和误报复核必须复用同一端口，但不在本任务中新增这些尚未解锁的应用服务。

## 4. 并发合同

1. 同一告警的原子更新由 PostgreSQL 行锁串行化，成功事务得到唯一、严格递增且连续的已提交序号。
2. 不同告警只锁各自主记录，不引入全局热点。
3. 状态动作先 CAS 后分配，CAS 失败者不消耗序号。
4. 无状态动作未来通过幂等唯一约束去重并由分配器串行；重复请求即使触发唯一冲突，也必须随事务回滚计数器增量。
5. 事务回滚允许下一成功事务复用未提交的序号；这不是重复，因为失败事务没有可见动作事实。
6. `alarm_action_log` 保持追加不可变；已提交动作不得删除以“修复”序号。

## 5. 必测场景

1. 首次创建动作序号为 1，第二次发生和恢复依次递增，且不依赖 `rowVersion` 数值。
2. 状态 CAS 失败、重复来源消息、重复恢复和同周期非法重开均不调用分配器。
3. 分配后在 action、Outbox、Inbox 完成任一点注入失败，事务模型回滚且下一成功动作取得相同的未提交序号。
4. 同一告警两个并发成功动作取得不同且严格递增序号；不同告警各自从 1 开始。
5. 同一幂等请求重放只保留一条动作，不消耗额外已提交序号。
6. SQL 合同包含 `tenant_id/site_id/id` 与 `RETURNING last_action_sequence`，并稳定拒绝 `MAX(sequence_no)`、`rowVersion()+2`、`row_version + 2` 和进程内分配。
7. V011 字段具备 `NOT NULL DEFAULT 0`、非负 CHECK 和中文 COMMENT；静态注释计数同步更新。
8. P02-M2-01、P02-M2-02B 定向测试及受影响 Reactor 编译继续通过，测试实际执行且 0 跳过。

并发单测可以使用确定性 fake 模拟原子分配和事务快照回滚；这只证明应用合同，不得表述为真实 PostgreSQL 行锁证据。
