## 4. 风险与控制

- 仅插入七行，锁影响局限于 `system_menu` 的短事务写入；脚本遇到错库、父菜单漂移、部分权限、
  语义漂移或 ID 占用时失败关闭。
- `psql -1 -v ON_ERROR_STOP=1` 保证七行原子提交，任何 guard/insert/verify 失败全部回滚。
- 权限行本身不产生用户能力；没有角色关联时，现有用户不会获得新权限。
- `power:system-template:manage` 属高权限，本窗口只建立权限事实，后续 canary 角色不得默认获得该权限。
