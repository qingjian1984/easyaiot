
### 步骤 3：启用查询开关（standard/full）

`.scripts/docker/.env.docker` 或部署环境追加：

```
EASYAIOT_TELEMETRY_QUERY_ENABLED=true
```

并在 `DEVICE/docker-compose.yml` iot-sink 服务的 environment 段加入该变量（当前未列），然后 `docker compose up -d iot-sink` 生效。

- local profile 已默认 `query.enabled=true`（本地联调无需变量）
- mini 档**不启用**（fail-closed，电力查询仅 standard/full）

### 步骤 4：gateway 路由生效

gateway 配置已落库（`/admin-api/telemetry/**` → sink-server）。若 gateway 容器为旧镜像需同步重建；配置来自仓库 `application.yaml` 挂载时 `docker restart iot-gateway` 即可。

### 步骤 5：WEB 部署

```bash
cd WEB && pnpm build   # 已验证通过
# dist/ 按现有流程发布到 web-service
```

新页面：`/telemetry/history`（前端静态路由，无需 DB 菜单）。

### 步骤 6：端到端验证

```bash
# 1) 经 gateway 直测（需登录 token，或临时用服务直连 48092）
curl -X POST http://localhost:48080/admin-api/telemetry/latest \
  -H "Authorization: Bearer <token>" -H "tenant-id: 1" \
  -H "Content-Type: application/json" \
  -d '{"series":[{"deviceIdentification":"<真实设备>","propertyCode":"<真实测点>"}]}'

# 3) 浏览器：遥测历史页 → 多测点查询 → 曲线渲染 → CSV 下载 → 质量码列显示
```
