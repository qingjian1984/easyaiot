## 3. 明确禁止

- 不调用产品绑定 API，不创建产品、设备、节点、发布单或 collector 投影；

- 不授予 import/upgrade/retire/system-manage 权限；
- 不通过数据库直写绕过 HTTP 权限、租户、幂等、审计或 Outbox；
- 不删除或篡改发布审计和不可变 PUBLISHED 版本来伪造回退。

## 4. 验收与停止条件

identity、draft、validate、publish 每步记录 HTTP 状态、稳定业务 code、服务端 ID、ETag 和 contentHash，禁止

产品/设备/绑定/release/projection 仍为 0，binding API=false，Kafka/DLQ 无异常积压。

任一步失败立即停止后续调用，不更换请求资产、不复用异请求幂等键、不直接修库。由于 PUBLISHED 模板与
审计是不可变事实，本窗口不承诺物理删除；异常处置须另立撤销/retire 窗口。
