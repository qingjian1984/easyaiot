## 2. 本轮裁决

| 议题 | 裁决 | 说明 |
|---|---|---|
| 数据库字段命名 | 采用 `id`、`row_version`、`device_identification` | 分别映射领域 `alarmId`、`version`、`deviceId`；JSON 仍使用领域名，禁止数据库列名泄漏为公共合同 |
| 升级时间事实 | 必须补 `last_escalated_at` | `escalation_level` 与最后升级时间共同表达正交升级事实 |
| 来源事件类型 | Envelope `eventType=device.alarm.source-event.v1` | `RAISED/RECOVERED` 固定放在 `payload.sourceAction`，不构成领域事件别名 |
| Envelope source | 固定 `iot-device` | 与 P02-M2-01 已冻结 Java 合同一致；外部来源先由受控适配器转换，适配器本轮不实现 |
| `alarmId` 位置 | `payload.alarmId` | “Envelope 逻辑必含 alarmId”不等于新增顶层字段；不破坏已冻结 Java Envelope |
| 正式领域 Schema | 按 6 个事件拆分 | 聚合 Schema 只作评审目录/联合校验，不能复制为单一生产 Schema |
| Inbox hash 冲突 | `QUARANTINED + ALARM_SOURCE_HASH_CONFLICT` | 保留首次 envelope hash；冲突正文不得覆盖既有事实，持久化隔离后才可确认消息 |
| Inbox 处理模型 | 同事务处理 | Inbox、来源映射、主记录、动作历史和 Outbox 同事务；提交前不得 ACK |
| Outbox 模型 | 租约 + 有界重试 + DEAD_LETTER | 过期 `PUBLISHING` 必须可重领；broker 确认后才标记 PUBLISHED |
| 不可变保护 | 数据库 trigger + 最小权限 | 发布/退役规则内容、来源映射和动作历史不能只依赖 COMMENT 或应用约定 |
| runner 接入 | 显式 review-only 步骤 | V011 不进入默认 apply 链；必须显式 `--step V011`、临时库门禁、审批标识和备份 |

## 3. 事务与 ACK 冻结边界

```text
校验版本/Schema/租户/来源
  → 计算 envelopeHash
  → 同一 PostgreSQL 事务：
       Inbox 仲裁
       + source mapping
       + alarm_record CAS
       + action log
       + alarm_outbox
       + Inbox PROCESSED
  → COMMIT
  → transport ACK/提交 offset
```

- 同 `messageId + envelopeHash`：返回 `DUPLICATE`，不重复业务副作用；已持久化裁决后可 ACK。
- 同 `messageId` 异 hash：把既有 Inbox 置为 `QUARANTINED`、记录稳定错误码并触发 critical；不得修改既有告警；隔离持久化后可 ACK。
- 可重试数据库/依赖错误：事务回滚，不 ACK，由 transport 有界重试。
- 未知主版本、非法 Schema 或 final 错误：持久化隔离并成功写入 DLQ 后可 ACK；DLQ 写失败不得 ACK。
- Outbox 发布：只有 broker 确认成功后才标记 `PUBLISHED`；崩溃留下的过期 `PUBLISHING` 由租约恢复。

`payload.payloadHash` 表示来源证据正文摘要；Inbox 的 `envelopeHash` 表示规范消息字节摘要。两者用途不同，不得互相替代或信任消息自报值代替本地计算。

## 4. 可冻结内容

- `iot-device` 为告警主记录、处置状态和领域 Outbox 唯一 owner。
- 九张逻辑表职责、同租户复合关联、告警周期唯一、状态/升级正交和误报双人复核方向。
- `INFO/NORMAL/IMPORTANT/EMERGENCY` 与七个主状态；EMERGENCY 不得进入 IGNORED。
- 来源事件与六个领域事件名称、Envelope 1.0、正整数 ID 字符串和 offset 时间。
- standard/full 共用表、Schema、状态机与代码；advanced 只增加策略和配额。mini 不执行 V011、不装配相关 Bean/任务/消费者。
- 回滚优先停新流量和切旧读；一旦存在业务/Inbox/Outbox/审计事实，不允许用 U011 删除。
