## 2. 唯一允许动作

- 用 access token 6120 按序调用 4 个 API（body 与冻结资产逐字节一致）：
  1. `POST /api/v1/power/model-templates`（identity，body = identity-request.json）
  2. `POST /api/v1/power/model-templates/canary-meter-123/drafts`（draft，body = draft-request.json）
  3. `POST /api/v1/power/model-templates/canary-meter-123/drafts:validate`（validate）
  4. `POST /api/v1/power/model-templates/canary-meter-123:publish`（publish，body = publish-request.json）
- 4 个 API 必须在同一 access token 有效期内完成（6120 expires 00:55:45，剩余约 20 分钟，需高效）；
- 执行方式由 owner 决定（浏览器 DevConsole + sessionStorage token / 受控 CDP 脚本），token 不入库/不进文档/不进聊天；
- Idempotency-Key / X-Request-Id / traceId 由执行器运行时生成，不预写入资产。

## 5. 失效条件（任一触发即停止，不重试）

- 任一 API 返非 2xx（identity 404/409、draft 422、publish 409/412 等）；
- access token 6120 过期（超过 00:55:45）；
- 资产 hash 漂移或基准提交 `1ec8e801` 不存在；
- 业务计数或迁移状态漂移。

- 任一 API 失败：立即停止，不调后续 API，不重试；

- access 6120 / refresh 6119 在窗口结束（成功或失败）后由独立 token 处置窗口撤销。
