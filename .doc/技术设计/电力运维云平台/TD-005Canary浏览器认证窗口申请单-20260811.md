## 1. 唯一允许动作

由用户本人在受控浏览器登录页输入 tenant=`测试租户`、username=`aoteman`、现有密码及必要验证码；必须
设置 `rememberMe=false`。只允许登录页静态资源、租户查询、验证码 get/check、`/system/auth/login` 和
`/system/auth/get-permission-info`；浏览器层必须阻断 `/api/v1/power/**` 及其他非认证 API。

成功后 access token 仅保留在该浏览器会话存储中，不导出、不显示、不复制到终端、仓库、文档或聊天。
验收只通过只读数据库元数据确认 user 113 新增一个未过期 access token、有效期不超过 1800 秒，并复核
role 111 权限与 tenant 122 空数据事实。

## 2. 明确禁止

- 不由自动化输入、读取、记录或恢复密码；密码和验证码必须由用户本人输入；
- 不选择“记住我”，不刷新 token，不读取 token 内容或摘要；
- 不调用电力、产品、设备、绑定或其他业务 API，不写 Canary；
- 不修改 API 开关、Secret、角色、数据库、Topic、Nacos、capability 或任何容器；
- 登录失败一次立即停止，不自动重试，不重置密码，不查询密码摘要；
- 本窗口成功不构成 Canary 写入批准。
