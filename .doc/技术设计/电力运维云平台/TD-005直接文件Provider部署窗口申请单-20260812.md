> 先例（**均不得复用**）：1.0.51 / 1.0.52 / 1.0.53 三次 Config Tree 部署均因 `POWER_MODEL_IDEMPOTENCY_SECRET_INVALID` 失败回退

## 0. 背景

1.0.53 失败根因：HMAC Secret 通过 `@Value` 散落 6 处，依赖 Spring Config Tree 把 `/run/secrets/easyaiot.power-model.idempotency-hmac-secret` 文件名→属性映射注入；该映射在生产容器多属性源下不稳定，属性为空，Guard fail-closed。

1.0.54 候选改为**应用内 fail-closed 直接文件 provider**：
- 新增 `PowerModelIdempotencySecretProvider`（`@Component`）读 `EASYAIOT_POWER_MODEL_HMAC_SECRET_FILE` 指向的文件，启动期严格校验 UTF-8/无 BOM/无换行/无 NUL/≥32 字节，异常消息只含原因类别；
- `PowerModelActivationGuard` + 4 写服务（Binding/Publish/Identity/Draft）统一构造注入 provider，删除全部 `@Value` secret 与 `spring.config.import: configtree`；
- Compose secret target 改为不含 `.` 的 `easyaiot_power_model_hmac`，activation preflight 同步检查新路径。

代码层验证：Java 17 main + test 编译 PASS；provider/ActivationGuard/SecretMount 合同 **30/30 PASS**（provider 16 + Guard 8 + SecretMount 6）；静态 grep 无 `@Value` secret 残留、无 `configtree`、provider 无日志输出；候选 JAR 含 `PowerModelIdempotencySecretProvider` + `PowerModelTemplateController` + 4 写服务全部类。

## 1. 唯一允许动作

- 以候选 JAR（SHA-256 `9dd1936…`）构建 `iot-module-device-biz` 镜像；
- 仅以 `--no-deps --force-recreate` 重建 `iot-device` 单容器；
- 保留现有运行配置：`full`、`release=true`、`events=true`、`template=true`、`binding=false`；
- 保留仓库外 HMAC Secret 文件不动；直接文件 provider 读容器内挂载 `/run/secrets/easyaiot_power_model_hmac`（由 `EASYAIOT_POWER_MODEL_HMAC_SECRET_FILE` 指向）；
- 部署前自动备份 `iot-device20`（仓库外 custom-format），保留旧镜像专用回退标签；
- 失败仅回退 `iot-device` 至 1.0.53 回退后的旧镜像 `4fa86930…705b`。

## 3. 验收（部署后只读核验）

- `iot-device` 容器 healthy、`restartCount=0`；

- 启动日志**无** `POWER_MODEL_ACTIVATION_INCOMPLETE`（`template=true` + release + events 组合有效）；
- 运行 JAR 含 `PowerModelTemplateController`（1.0.48 identity 404 根因已修）；
- 未认证路由探针：`POST /api/v1/power/model-templates` 返 **401**（非 404，证明模板路由已注册）；
- 数据库积压 `0/0/0/0`（Outbox/Inbox/release/projection）、业务计数 `4/4/17`、`invalid index=0`、迁移 `V001～V007` 7/7 SUCCEEDED 不变；

## 4. 失效条件（任一触发即自动回退 iot-device 并停止）

- 容器在 150 秒有界窗口内未达 healthy；
- 启动日志含 `POWER_MODEL_IDEMPOTENCY_SECRET_INVALID` 或 `POWER_MODEL_ACTIVATION_INCOMPLETE`；
- 路由探针返 404（模板 Controller 仍缺失或路由未注册）；
- 数据库业务计数或迁移状态漂移。
