## 1. 目标

把 V011/U011 接入 ADR-013 的受控迁移校验能力，并建立静态与隔离临时 PostgreSQL 合同。任务只证明候选迁移资产可受控、可重放、失败可回滚；不授权目标/共享/生产库执行，也不启用告警 capability。

## 3. runner 约束

- V011 必须是显式 review-only 步骤，不进入 `APPLY_STEPS` 默认链。
- 只有同时满足显式 `--step V011`、`TD006_REVIEW_ONLY=1`、非空审批标识、备份目录和临时库实例门禁才允许执行。
- 临时库门禁必须核对实际连接身份与 `current_database()`；仅匹配数据库名字符串不充分。
- 同 migration ID 同 hash 已成功返回 SKIPPED；同 ID 异 hash 在任何 DDL 前阻断。
- V011 事务边界由 runner 独占；资产本身不得 COMMIT。
- U011 只作为显式 review-only 卸载步骤；任一业务、Inbox、Outbox 或审计事实非空即整体拒绝。
- 默认 dry-run；不得增加跳过备份、跳过审批或允许共享库的参数。

## 4. 必测合同

1. 静态：九表、全部列中文注释，V011 无 BEGIN/COMMIT，U011 有非空拒绝。
2. runner：默认计划不含 V011；未显式 review-only 门禁时稳定拒绝且零 DDL。
3. 首次：隔离临时库 V011 单事务成功、history/hash/evidence 正确。
4. 重放：同 ID/hash SKIPPED、零结构变化。
5. 漂移：同 ID 异 hash、同名表/约束/索引签名漂移均在 DDL 前阻断。
6. 事务：中途反例失败后九表零残留、history 记录符合 ADR-013。
7. 约束：周期唯一、同租户 FK、紧急忽略拒绝、规则发布唯一、误报复核分人、Outbox/Inbox hash 格式。
8. 不可变：发布/退役规则内容 UPDATE/DELETE 拒绝，动作历史与来源映射 UPDATE/DELETE 拒绝。
9. 租约：过期 PUBLISHING 可被候选 claim 查询命中，未过期租约不可重领。
10. 卸载：任一表非空 U011 全拒绝；空表卸载成功；history 保留。

临时数据库执行必须在 Sol 对静态实现复核后另行解锁。本任务单本身不是执行授权。

静态实现与 58 项假命令验收结果见 [P02-M2-02A 本地静态验收记录](./P02-M2-02A-本地静态验收记录.md)。该记录没有解锁临时库或任何真实 DDL。

## 5. 完成定义

- 所有静态合同与 runner 反例通过，并记录实际命令、退出码和摘要。
- 若获准执行临时库合同，记录 PostgreSQL 版本、隔离实例、创建/销毁事实和无目标库连接证据。
- Sol 逐文件复核默认 apply 链未扩大、无危险旁路、无用户文件混改。
- 交付状态最多为 `Verified-Local / Production Apply Prohibited`。

## 6. 排除项

- 不生成 backfill，不读取旧告警生产数据。
- 不修改 capability manifest、应用启动配置或生产 Topic。
- 不执行目标、共享、演示长期库或生产库 DDL。
- 不把 U011 当作有数据后的业务回滚；有事实时只允许应用层停流与保留表。
