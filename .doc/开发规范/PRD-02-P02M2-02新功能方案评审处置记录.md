## 3. N-02 实现禁区

- 不得仅增加注释后保留 `rowVersion+2` 并宣称关闭；
- 不得在无告警行锁或原子分配器时执行 `SELECT MAX(sequence_no)+1`；
- 不得用全局 Snowflake/数据库 sequence 冒充告警内单调序号，除非先修改合同允许稀疏且证明严格单调；
- 不得在 C0 中修改 V011、02B Java 或测试；
- 必须覆盖来源发生、恢复、人工状态动作、升级、忽略到期和误报复核并发交错。
