# PRD-03：可视化 SCADA 与视频联动

> PRD ID：POWER-PRD-003  
> 版本：1.2.0  
> 状态：In Review  
> 优先级：P0  
> 目标里程碑：M2  
> 基线：[《平台功能计划》1.4.0](../../架构设计/平台功能计划.md)、[《EasyAIoT 项目开发宪法》1.4.0](../../开发规范/EasyAIoT项目开发宪法.md)

## 1. 目标

为管理者和值班人员提供从多站点总览、站点看板、一次系统图到设备详情和现场视频的分层可视化体验。

## 2. 建设方式

| 分类 | 内容 |
|---|---|
| 直接复用 | VISUALIZE 大屏、FUXA、视频播放、录像回放 |
| 修改增强 | 站点聚合 API、实时刷新、告警钻取、视频绑定 |
| 新增 | 电力图元库、一次图拓扑语义、告警视频联动模板 |

## 3. 信息架构

```text
集团总览
└── 区域/园区
    └── 站点看板
        ├── 一次系统图
        ├── 设备监控
        ├── 环境监控
        ├── 告警中心
        ├── 视频监控
        ├── 能源概览
        └── 运维概览
```

## 4. 功能需求

### 4.1 站点看板

- 展示站点容量、电压等级、运行状态、在线设备、关键负荷和活动告警。
- 展示温湿度、SF6、烟雾、水浸和入侵状态。
- 展示当日/当月用能、最大需量和用能趋势。
- 展示待巡检、未关闭缺陷和超期工单。
- 指标点击可进入来源页面，禁止只展示不可追溯数字。

### 4.2 一次系统图

- 提供母线、进线、馈线、开关、刀闸、变压器、电容器和计量表图元。
- 图元可绑定遥信、遥测、告警和控制服务。
- 颜色和动画表达状态时必须同时提供文字或图标，避免只依赖颜色。
- 支持在线编辑、版本保存、预览、发布和回滚。
- 发布版本与草稿隔离，编辑错误不得影响生产展示。
- 控制操作必须跳转或调用安全遥控流程，不允许图元直接绕过审批。
- 同一画面草稿采用版本号和乐观锁防止静默覆盖；检测到并发修改时必须提示差异并要求合并或另存。发布/回滚只改变生产指针，不删除其他人的草稿和历史版本。

### 4.3 历史曲线与报表入口

- 一次图和看板可从设备或测点进入历史曲线。
- 支持时间范围、粒度、多测点、统计值和导出。
- 页面展示数据质量和缺失区间。

### 4.4 视频联动

- 摄像机可绑定站点、区域、设备和预置位。
- 告警发生时可触发预置位、抓拍或指定时长录像。
- 告警详情直接播放对应时间段录像。
- 视频不可用时仍保留告警并展示失败原因。
- 联动配置按站点、告警规则和摄像机授权；并发数、预置位占用和录像时长受 capability 配额限制。同一告警的多个视频动作分别记录结果，任何失败都不得回滚或阻止告警创建。
- 事故追忆拥有告警时间线和证据索引，VIDEO/iot-sink 保存并提供媒体证据；PRD-02 与本 PRD 共用同一 `alarmId` 和证据引用，不复制事故记录。

## 5. 用户故事

- 作为集团负责人，我希望一屏比较所有站点的安全和能效状态。
- 作为值班人员，我希望从一次图直接定位异常设备并查看数据和视频。
- 作为实施人员，我希望复用模板快速创建新站点的一次图。
- 作为审计人员，我希望确认当时发布的是哪个画面版本和点位配置。

## 6. 验收标准

- 站点看板的指标均能钻取到明细或来源数据。
- 一次图可实时显示至少开关状态、电流、电压、功率和告警。
- 图元绑定错误在发布前被校验并阻止发布。
- 已发布版本可一键回滚到上一版本。
- 告警可关联摄像机抓拍和对应录像时间段。
- 用户只能查看有数据权限的站点、画面和摄像机。
- 大屏断线后恢复连接，不需要刷新整个浏览器页面。

## 7. 非功能要求

- 画面数据刷新频率可配置，避免所有点位高频轮询。
- 实时画面优先使用 WebSocket 增量订阅；standard 单画面默认最多 500 个实时点、最快 1 秒刷新，full 配额由 manifest 提高。断线重连后先获取版本化快照再续订增量，禁止为每个图元独立轮询。
- 多屏展示不得绕过登录和临时访问授权。
- 视频凭据不得暴露在页面源码或持久 URL 中。
- mini 不提供电力看板、SCADA 或电力视频联动。
- standard 提供 WEB 内置站点总览、基础一次图查看、实时视频和基础告警抓拍关联。
- standard 的基础一次图支持查看、缩放、设备/测点详情钻取和安全遥控申请入口，但不提供画面编辑、发布、脚本或 FUXA 运行时。
- full 在同一数据/API 契约上增加 VISUALIZE 大屏编辑发布、FUXA Web SCADA、预置位联动和事故录像证据。
- standard/full 共用站点聚合、点位绑定、实时订阅、视频鉴权和安全遥控 API；不得为 full 复制一套 SCADA 数据服务。
- 所有看板、一次图和视频钻取使用 PRD-00 的稳定资源 deep link；目标页面重新校验权限，禁止在 URL 中携带凭据或授权结果。
