# EasyAIoT 电力运维云平台 · 功能汇总与多端支持

> 版本：1.0.0
> 日期：2026-08-10
> 基线：[平台功能计划 1.4.0](../架构设计/平台功能计划.md) / [EasyAIoT 项目开发宪法 1.5.0](../开发规范/EasyAIoT项目开发宪法.md) / [PRD-00 产品总纲 1.2.0](../产品需求/电力运维云平台/PRD-00-产品总纲.md)
> 说明：本文为功能速览 + 多端支持汇总，详细功能点见 [功能列表.md](功能列表.md)。

## 1. 项目概述

EasyAIoT 电力运维云平台在既有 IoT 底座上构建电力行业能力，形成「监测—告警—处置—运维—分析」闭环。平台覆盖**六大业务领域 + 平台基础能力**，按 M1～M6 六里程碑分阶段交付，支持 **WEB / APP / 大屏 / SCADA** 四端统一体验，仅面向 standard / full 两档部署（full 是 standard 的严格能力超集）。

## 2. 多端支持总览

平台一套业务能力，多端差异化呈现。终端定位与档位如下：

| 终端 | 定位 | 核心场景 | 部署档位 |
|---|---|---|---|
| **WEB**（PC 浏览器） | 全功能控制台 | 配置管理、实时监控、历史分析、告警处置、安全遥控、报告审批、系统管理 | standard / full |
| **APP**（移动端） | 现场作业终端 | 值班告警、扫码巡检、工单执行、缺陷上报、设备档案、位置签到、遥控申请 | standard / full |
| **大屏**（VISUALIZE） | 集中监控展示 | 站点看板、一次系统图编辑发布、多站点总览、能源概览、报告展示 | **full only** |
| **SCADA**（FUXA Web SCADA） | 专业组态运行 | 一次系统图组态、图元绑定运行、控制操作（走安全遥控） | **full only** |

**通知渠道**（不属终端，但多端触达）：APP 推送 / 站内信 / 短信 / 电话 / 企业微信，standard / full 均支持。

> 四端共用同一后端 API、数据模型、权限点、事件契约与状态机；前端不持有业务数据库/Redis/Kafka 凭据，所有操作经服务端校验。APP 离线数据加密保存、幂等同步。

## 5. 各终端能力清单

### 5.1 WEB（PC 浏览器，standard / full）

- **配置管理**：站点/配电房/设备树、物模型模板、点表导入、采集协议、告警规则、巡检计划、计量点、电价方案、报告模板
- **实时监控**：站点看板、一次系统图查看（standard）/ 编辑发布（full）、设备实时状态、历史曲线
- **告警处置**：告警列表、确认、处理、事故追忆、证据回放、维护模式
- **安全遥控**：申请、审核（双人）、联锁预检、执行、回执、审计查询
- **运维管理**：设备档案、二维码管理、巡检统计、缺陷定级、工单派单/验收
- **能源分析**：分类分项、同环比、需量、电费、电能质量（full）
- **报告**：手动/计划生成、审批、查阅、钻取追溯、订阅发送（full）
- **系统管理**：租户、角色、权限、capability、值班表、渠道配置

### 5.2 APP（移动端，standard / full）

> 一级业务入口「运维」（capability 驱动，mini / 无权限不创建空白入口）

- **扫一扫**：扫码进入设备详情（鉴权后展示有权信息）
- **我的巡检**：扫码确认、数值/单选/多选/文本/照片/视频/语音/签名、离线执行、到场证据、异常一键缺陷
- **我的工单**：接单、转派（full）、暂停（full）、处理、提交、验收
- **缺陷上报**：现象/等级/图片/发现人
- **设备档案**：扫码查看档案、附件、质保/试验到期提醒
- **告警处置**：告警查看、确认、处理、遥控申请
- **位置签到**：定位授权、签到、轨迹上传（仅工作任务/配置时段）
- **消息中心**：告警/工单/缺陷通知
- **离线能力**：弱网离线作业、幂等 ID 同步、附件独立续传、加密保存

### 5.3 大屏（VISUALIZE，full only）

- 集团/区域/园区多站点总览与排行
- 站点看板（容量/电压等级/状态/在线设备/关键负荷/活动告警/环境/用能/运维概览）
- 一次系统图大屏编辑、发布、版本管理
- 能源概览（当日/当月用能、最大需量、趋势）
- 报告展示、事故证据集中呈现
- 多屏展示不绕过登录与临时访问授权

### 5.4 SCADA（FUXA Web SCADA，full only）

- 一次系统图专业组态与运行时
- 图元绑定遥信/遥测/告警/控制服务
- 颜色与动画状态表达（同时提供文字/图标，不只依赖颜色）
- 控制操作必须跳转或调用安全遥控流程，不允许图元直接绕过审批
- 现场可配置硬禁用，平台不得绕过

### 5.5 通知渠道（standard / full，非终端但多端触达）

- APP 推送、站内信、短信、电话、企业微信
- 关键告警未确认时按时间和角色逐级升级
- 渠道故障不阻止告警创建；通知持久化后异步发送，故障按渠道退避

## 6. 部署档位 × 终端 矩阵

| 终端 / 能力 | mini | standard | full |
|---|:---:|:---:|:---:|
| WEB 电力监控/告警/运维/能源/报告 | ✗ | ✓ 基础 | ✓ 全功能 |
| APP 运维入口 | ✗ | ✓ 基础巡检/工单 | ✓ 完整 SLA/轨迹/评价 |
| 大屏 VISUALIZE 编辑发布 | ✗ | ✗ | ✓ |
| SCADA FUXA 组态 | ✗ | ✗ | ✓ |
| 视频联动 | ✗ | 基础抓拍/回放 | 完整事故证据 + 预置位联动 |
| 安全遥控 | ✗ | 可选（启用即完整门禁） | 完整门禁 + 集中治理 |
| 多站点经营分析 | ✗ | ✗ | ✓ |

> 三档复用同一代码主线；mini 通过 capability manifest 关闭全部电力能力，full 仅启用 standard 之上的高级模块和配额。Capabilities(standard) ⊂ Capabilities(full) 必须由自动化测试证明。

## 7. 里程碑与多端交付节奏

| 里程碑 | 周期 | 产品结果 | 主要交付终端 |
|---|---:|---|---|
| M1 数据接入 | 6～8 周 | 真实站点数据连续入库、可查历史 | WEB |
| M2 无人值守 | 6～8 周 | 告警/通知/视频证据/处置闭环 | WEB + APP + 大屏（full） |
| M3 安全控制 | 4～6 周 | 安全遥控全链路 | WEB + APP + SCADA（full） |
| M4 运维闭环 | 8～10 周 | 扫码巡检/缺陷/工单闭环 | APP + WEB |
| M5 能源基础 | 8～10 周 | 自动抄表/分类分项/基础月报 | WEB + 大屏（full） |
| M6 高级分析 | 8～12 周 | 需量/电费/电能质量/综合月报 | WEB + 大屏（full） |

## 8. 平台基础能力（跨终端共享）

| 能力域 | 说明 |
|---|---|
| 部署档位与单一实现 | standard/full 同代码主线；mini 关闭电力 |
| Capability Manifest | 统一能力清单，后端/前端/安装器同源读取 |
| 租户与权限 | 复用 iot-system；遥控申请/执行与审核权限分离 |
| 统一遥控入口 | iot-device 唯一责任，/device/control/**，全链路幂等 |
| TelemetryStore | standard PostgreSQL 分区 / full TDengine，业务无感 |
| 事件总线 Kafka | 7 类版本化事件，消费者幂等，双发对账升级 |
| 统一调度与任务 | 抄表/报告/告警复用调度、幂等、重试、可观测 |
| 文件存储 | MinIO；APP 离线加密、幂等同步 |
| 时间与时区 | UTC 保存 + 站点 IANA 时区，左闭右开周期 |
| 可观测性 | 采集率/延迟/送达率/SLA/积压 |
| 数据质量治理 | 异常留痕、P95 ≤5s、断点续传/死信/补偿 |
| 隐私合规 | 定位授权/限时、轨迹默认 90 天 |
