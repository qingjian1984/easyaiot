# Infra Layer — 中间件与部署架构

> 基于整体架构文件 V9.17.0 + 部署脚本与 Docker Compose 配置深入分析
> 规模: 12 个中间件 / 18 个 Docker Compose 文件 / 5 套平台安装脚本 / 3 种部署规格

---

## 一、总体定位

中间件与部署层是 EasyAIot 的 **基础设施底座**，提供数据存储、消息通信、服务治理、对象存储、流媒体、向量检索等 12 个基础中间件的容器化部署，并通过 Docker Compose 实现一键部署，支持 3 种规格适配从 4GB 边缘盒子到 20GB+ 企业全栈一体机。

| 指标 | 数据 |
|------|------|
| 中间件总数 | 12 个 |
| Docker Compose 文件 | 16 个 |
| 部署脚本 | 4 套 (Linux x86/ARM/Kylin/macOS) |
| 数据库 | 8 个 PostgreSQL 业务库 |
| 部署规格 | mini (4G) / standard (16G) / full (20G+) |
| 默认网络 | easyaiot-network (Docker bridge) |
| 容器总数 (full) | 30+ 个 |
| 安装 Shell 脚本 | 145+ 个 |

### 5.2 为什么混合网络?

| 模式 | 原因 |
|------|------|
| **bridge** | 中间件间服务发现 (Docker DNS)、安全隔离 |
| **host** | 流媒体低延迟 (SRS)、UDP 广播 (ONVIF 发现)、SIP 信令 (GB28181) |
| **extra_hosts** | WEB 容器需要访问 host 网络的服务 (通过 host-gateway 地址) |

```

          │     1. PostgreSQL (init-databases 前置容器)

          │     3. iot-device/dataset/node/visualize/file/message/sink
          │        (等待 iot-infra 健康)
          │     4. iot-sink (额外等待 iot-system)

```

### 6.4 Docker vs 原生进程

| 运行方式 | 组件 | 原因 |
|----------|------|------|
| **Docker 容器** | 全部中间件 | 环境隔离、快速部署、版本管理 |
| **Docker 容器** | Java 微服务 (11 个) | 统一编排、健康检查、日志收集 |
| **Docker 容器** | AI / VIDEO Python 服务 | Python 环境隔离、CUDA 驱动透传 |
| **Docker 容器** | WEB / APP / VISUALIZE | Nginx 容器化、多阶段构建 |
| **Host 原生** | NODE Agent | systemd 管理、开机自启、SSH 远程部署 |
| **Host 原生** | EDGE CLI | 边缘低资源 (~512MB)、pip 安装即可运行 |
| **Host 原生** | TASK C++ | 编译为原生二进制、GPU 加速、低延迟 |

## 九、关键架构模式

### 9.1 不可变部署 (Immutable Deploy)

源码以 `volume` 方式挂载到容器中，更新代码只需 `git pull` + 重启容器，无需重新构建镜像。

### 9.2 启动顺序编排

```
PostgreSQL-Init → PostgreSQL
               → Nacos / Redis / SRS (并行启动)
               → Kafka / MinIO / Milvus (并行启动)
               → iot-system → iot-infra → iot-device/dataset/node/... (并行启动)
```

使用 Docker Compose `depends_on` + `healthcheck` + 自定义 wait-for 脚本。

### 9.3 镜像拉取 vs 本地构建

```
┌─ 预构建模式 (推荐): registry 拉取 → 跳过本地构建 (节省 20-30 分钟)
└─ 本地构建模式: Maven/gradle/pnpm/pip 编译 → Docker 构建
   └─ .build-cache/ 缓存依赖 → 增量构建加速
```

### 9.4 跨平台适配

| 平台 | 差异处理 |
|------|----------|
| Linux x86 | 标准部署 |
| Linux ARM | JVM/镜像架构自动检测、ARM 兼容镜像 |

> **一句话总结:** 中间件与部署层是 EasyAIot 的容器化基础设施底座，12 个中间件通过 Docker Compose 统一编排，3 种部署规格 (4G/16G/20G+) 弹性适配从边缘到云端，5 套平台安装脚本实现一键部署，bridge+host+extra_hosts 混合网络兼顾服务发现与流媒体低延迟，8 个 PostgreSQL 业务库 + TDengine 时序 + Redis 缓存构成完整数据存储栈。
