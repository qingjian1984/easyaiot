# Hardware Layer — 硬件层详细架构

> 基于整体架构文件 V9.18.0 + 部署文档 + 协议适配层分析
> 定位: EasyAIot 平台对接的物理设备层，是 IoT 感知与执行的末端

---

## 一、总体定位

硬件层是 EasyAIot IoT 架构的 **感知与执行末端**，涵盖平台支持接入的各类物理设备，包括视频监控设备、环境传感器、工业执行器和无人机等。硬件层本身不包含 EasyAIot 代码，但平台的协议适配层 (iot-sink) 为这些设备提供了丰富的接入能力。

| 指标 | 数据 |
|------|------|
| 视频协议 | GB28181 / ONVIF / RTSP / 海康ISAPI / 大华CGI |
| 工业协议 | Modbus TCP/RTU / OPC UA / MQTT |
| 厂商支持 | 海康、大华、大疆等 |
| 流媒体协议 | RTMP / HTTP-FLV / HLS / WebRTC |
| 部署形态 | 工控机 / 嵌入式开发板 / 企业服务器 |

## 三、视频监控设备

### 3.1 接入协议矩阵

| 协议 | 标准 | 端口 | 发现方式 | 适用设备 |
|------|------|------|----------|----------|
| **GB/T 28181** | 国标 | 5060 (SIP) | SIP 注册 | 公安/交通国标摄像头 |
| **ONVIF** | 国际标准 | 80/8080 | WS-Discovery | 主流网络摄像头 |
| **RTSP** | IETF RFC | 554 | 手动配置 | 通用 IP 摄像头 |
| **海康 ISAPI** | 私有(HTTP) | 80/443 | HTTP API | 海康全系列 |
| **大华 CGI** | 私有(HTTP) | 80/443 | HTTP API | 大华全系列 |
| **RTMP** | Adobe | 1935 | 推流 URL | 无人机/编码器 |

### 3.2 视频设备接入流程

```
摄像头/NVR
  │
  ├── GB28181 接入:
  │     ├── iot-gb28181 → SIP Server (端口 5060)
  │     ├── iot-gb28181 → 设备目录同步
  │     └── 点播时: iot-gb28181 → SDP 协商 → RTP 流 → SRS/ZLMediaKit
  │
  ├── ONVIF 接入:
  │     ├── VIDEO 服务 → ONVIF Discovery (WS-Discovery 广播)
  │     ├── 获取设备能力 + 媒体 URI
  │     └── RTSP 拉流 → OpenCV/FFmpeg 解码
  │
  ├── RTSP 接入:
  │     ├── 手动配置 RTSP URL
  │     └── VIDEO 服务 → FFmpeg 拉流 → 分析
  │
  └── 海康/大华 SDK:
        ├── SDK API 登录/预览/PTZ/告警订阅
        └── 私有协议拉流 → 转 RTMP → SRS
```

### 3.3 支持的设备类型

| 设备类型 | 接入方式 | 能力 |
|----------|----------|------|
| **网络摄像机 (IPC)** | GB28181/ONVIF/RTSP | 实时预览、PTZ 控制、告警订阅 |
| **NVR 录像机** | 海康/大华 SDK | 多通道管理、录像回放、设备发现 |
| **编码器** | RTMP/RTSP | 视频推流、音频对讲 |
| **解码器** | 私有协议 | 上墙显示、分屏输出 |
| **门禁/对讲** | SIP/私有协议 | 开门控制、可视对讲 |
| **无人机** | RTMP | 实时图传、GPS 叠加 |

## 四、物联网传感器与执行器

### 4.1 数据采集链路

```
传感器/执行器
  │
  ├── Modbus TCP/RTU ──→ iot-sink (Modbus 轮询)
  │     ├── 温湿度传感器、气体检测仪
  │     ├── 电表/水表 (Modbus RTU)
  │     └── PLC 可编程控制器
  │
  ├── OPC UA ──→ iot-sink (OPC UA Client)
  │     ├── 工业设备、DCS/SCADA 系统
  │     └── 机床、传送带、包装机
  │
  ├── MQTT ──→ EMQX → iot-sink
  │     ├── NB-IoT/4G DTU (低功耗广域网)
  │     ├── 智能网关 (边缘协议转换)
  │     └── WiFi/以太网直连设备
  │
  └── TCP/HTTP ──→ iot-sink (自定义协议)
        └── 第三方系统对接、遗留设备
```

### 4.2 支持的传感器类型

| 类别 | 典型设备 | 接口 | 数据特征 |
|------|----------|------|----------|
| **环境** | 温湿度、气压、光照、风速 | Modbus RTU | 低频 (1-10 min) |
| **安防** | 烟感、门磁、红外、紧急按钮 | MQTT/Zigbee | 事件驱动 |
| **工业** | 压力、流量、液位、振动 | Modbus/OPC UA | 高频 (1-10 s) |
| **能源** | 电表、水表、气表 | Modbus RTU | 定时上报 |
| **位置** | GPS/北斗、RFID、UWB | MQTT/TCP | 定时/事件 |

### 4.3 执行器控制

| 类型 | 控制方式 | 安全要求 |
|------|----------|----------|
| **继电器开关** | MQTT 指令 → Modbus 线圈写 | 需确认回执 |
| **阀门控制** | OPC UA 方法调用 | 操作日志审计 |
| **电机/变频器** | Modbus 寄存器写 | 频率限制保护 |
| **PLC 触发** | OPC UA / Modbus | 互锁验证 |

## 五、边缘计算硬件

### 5.1 三种边缘部署形态

```
┌──────────────────────────────────────────────────────────────┐
│  工控机 / 企业服务器 (推荐 16GB+)                              │
│  ├── OS: Ubuntu 22.04 / CentOS 7 / 麒麟 Linux                │
│  ├── 部署: Docker Compose (standard/full)                    │
│  ├── 组件: NODE Agent (systemd) + TASK C++ + AI/VIDEO        │
│  └── 场景: 大型工厂、园区、城市路口                            │
├──────────────────────────────────────────────────────────────┤
│  边缘盒子 / 安防一体机 (4GB+)                                  │
│  ├── OS: Linux (ARM/x86)                                     │
│  ├── 部署: Docker Compose (mini)                             │
│  ├── 组件: VIDEO + AI + WEB + NODE Agent                     │
│  └── 场景: 零售店、小型停车场、家庭安防                        │
├──────────────────────────────────────────────────────────────┤
│  开发板 / 嵌入式 (~512MB)                                     │
│  ├── OS: Linux ARM                                           │
│  ├── 部署: RUNTIME C++ 原子模式 (executor=cpp，轻量二进制)    │
│  ├── 组件: 拉流 → YOLO 推理 → MQTT 告警上报                   │
│  └── 场景: 单点监控、野外部署、无人机机载                      │
└──────────────────────────────────────────────────────────────┘
```

### 5.2 硬件需求对比

| 规格 | 最小 RAM (推荐) | 典型硬件 |
|------|-------------|----------|
| **full** | 20 GB | Dell R750 / 华为 Atlas |
| **standard** | 16 GB | 研华工控机 / Jetson Orin |
| **mini** | 4 GB | 树莓派 5 / 海思 Hi3559A |
| **RUNTIME (C++)** | 512 MB | RK3566 等 ARM 开发板 |

> **注:** CPU 和磁盘要求未在部署脚本中强制执行，以上为推荐配置。GPU 为可选加速部件。

## 六、数据上行与指令下行

### 6.1 传感器数据上行

```
硬件层
  │
  ├── 定时上报 (如每 5 秒)
  │     └── Modbus Master 轮询 → TCP/RTU → iot-sink
  │
  ├── 事件上报 (如告警触发)
  │     └── MQTT Publish → EMQX → iot-sink
  │
  └── 批量上报 (如历史数据同步)
        └── OPC UA Historical Read → iot-sink

数据到达 iot-sink 后:
  ├── Redis: 实时设备影子 (最新状态)
  ├── TDengine: 时序历史数据
  └── Kafka: 告警/后处理事件
```

### 6.2 指令下行

```
WEB/APP 控制指令
  │
  ├── iot-device: 指令合法性校验
  ├── iot-sink: 协议编码 (Modbus/OPC UA/MQTT)
  │
  └── 硬件层执行
        ├── 继电器吸合/断开
        ├── 阀门打开/关闭
        ├── 电机启动/停止/调速
        └── 云台旋转/变焦/预置位
```

### 6.3 协议适配层次

```
┌─────────────────────────────┐
│  应用层                      │
│  iot-device: 物模型/产品定义 │
├─────────────────────────────┤
│  协议适配层                   │
│  iot-sink: 协议编解码/数据转换│
├─────────────────────────────┤
│  传输层                      │
│  MQTT/TCP/HTTP/Vert.x       │
├─────────────────────────────┤
│  网络层                      │
│  Ethernet/WiFi/4G/NB-IoT    │

│  硬件层                      │
│  传感器/执行器/摄像头         │
└─────────────────────────────┘
```

## 七、视频流路径

### 7.1 实时预览

```
摄像头 (RTSP)
  │
  ├── SRS: RTSP 拉流 → 转 HTTP-FLV/WebRTC/HLS
  │     └── WEB/APP: Jessibuca/EasyPlayer 播放
  │
  └── VIDEO: OpenCV/FFmpeg → AI 推理 → 推流 (RTMP → SRS)
```

### 7.2 GB28181 国标

```
GB28181 摄像头
  │
  ├── SIP 注册: → iot-gb28181 (SIP Server :5060)
  ├── 设备目录: → iot-gb28181 (设备管理)
  ├── 实时点播: INVITE → SDP → RTP → SRS/ZLMediaKit
  └── 录像回放: 历史媒体查询 → RTP 流
```

### 7.3 AI 推理流

```
摄像头 → RTSP 拉流
  │
  ├── C++ TASK / RUNTIME: 边缘端实时推理 (YOLOv11 ONNX)
  │     ├── 绘制检测框 → RTMPEncoder → 推流
  │     └── 告警 → AlgoMqttBus (MQTT → iot-sink)
  │
  └── Python VIDEO: 服务端推理 (YOLO v8/v11)
        ├── 帧提取 → YOLO 推理 + ByteTrack 跟踪
        ├── 告警 → Kafka → iot-message (邮件/短信/钉钉/飞书)
        └── 抓拍 → MinIO 存储
```

## 八、关键设计原则

| 原则 | 说明 |
|------|------|
| **协议无关** | 物模型 (TSL) 抽象设备能力，与底层协议解耦 |
| **边缘优先** | 关键告警在边缘本地决策，不依赖云端 |
| **离线自治** | 网络中断时边缘持续运行，恢复后数据补传 |
| **0 磁盘占用** | RUNTIME 原子模式不落本地业务盘 (告警经 MQTT 上行、媒体归 NFS/MinIO)，降低硬件成本 |
| **即插即用** | GB28181/ONVIF 自动发现，减少人工配置 |
| **灰度适配** | 3 种规格从 512MB 到 20GB+，弹性适配各类硬件 |
