## 五、数据流

### 5.1 传感器数据流

```
传感器 / RTU 采集器网关
  │ Modbus TCP/RTU / OPC UA / MQTT(→EMQX) / TCP / HTTP
  ▼
iot-sink (48086)
  ├─ Redis (实时设备影子)
  ├─ TDengine (时序历史数据)
  └─ Kafka (告警/后处理)
        │
        ▼
  iot-device (48083) → WEB / APP 仪表盘
```

### 5.2 视频流

```
GB28181 摄像头 / ONVIF / 大疆无人机
  │ SIP 注册 / 设备发现
  ▼
iot-gb28181 (48089) / SRS 流媒体
  │ RTSP/RTMP 拉流
  ▼
VIDEO (6000) → 6 子服务
  ├─ MinIO (抓拍/录像)
  ├─ Kafka (告警事件)
  └─ Milvus (人脸向量)
        │
        ▼
  iot-sink (后处理推送) → 邮件/短信/钉钉/飞书/微信
```

### 5.3 AI 全链路闭环

```
数据采集 → iot-dataset 标注
         → AI train 训练 (YOLO/SAM)
         → AI export 导出 (ONNX/TensorRT)
         → AI deploy 部署
         → VIDEO 实时推理 / TASK 边缘推理
         → iot-sink 后处理 → 告警通知
```

### 5.4 指令下发流

```
WEB / APP
  ▼
iot-gateway (48080)
  ▼
iot-device → Kafka/RocketMQ
  ├─ iot-sink → Modbus/OPC UA/MQTT → 传感器/执行器
  └─ iot-node → NODE Agent (9100) → TASK C++ 推理
```

## 六、部署架构

### 6.1 三种部署规格

| 规格 | 推荐内存 | 适用硬件 | 启用的核心服务 |
|---|---|---|---|
| **mini** | ≥ 4 GB | 边缘盒子（4GB 工控机、安防一体机） | iot-system + VIDEO + AI + WEB + PostgreSQL/Redis/SRS。**无** Nacos/Gateway/Kafka/EMQX/TDengine/MinIO |
| **standard** | ≥ 16 GB | AI 一体化摄像头、智能摄像机 | 含 Nacos/Kafka/EMQX/MinIO/Milvus。**无** TDengine/Node-RED/iot-device |
| **full**（默认） | ≥ 20 GB | 企业级全栈一体机 | **全部**中间件 + 全部业务模块 + APP H5 + 工业协议演示 |

### 6.2 部署方式

| 系统 | 脚本 | 方式 |
|---|---|---|
| Linux x86 | `.scripts/docker/install_linux.sh` | Docker Compose 全容器化 |
| Linux ARM | `.scripts/docker/install_linux_arm.sh` | Docker Compose |
| macOS | `.scripts/docker/install_mac.sh` | Docker Compose |
| Windows | `.doc/部署文档/平台Windows部署文档_zh.md`（手动） | 原生安装，仅 SRS 用 Docker |

### 6.3 Docker 与原生进程分界

| 运行方式 | 组件 |
|---|---|
| **Docker 容器** | DEVICE 全 11 个 Java 微服务 / AI / VIDEO / WEB / APP |
| **Docker 容器** | PostgreSQL / Redis / Nacos / Kafka / MinIO / TDengine / EMQX / SRS / ZLMediaKit / Milvus / Node-RED |
| **Host 原生进程** | NODE Agent（systemd，`/opt/easyaiot/node-agent`） |
| **Host 原生进程** | EDGE CLI（`python -m edge run`） |
| **Host 原生进程** | TASK C++（编译后的二进制） |
| **Host 原生进程** | mqtt-demo / industrial-demo / modbus-demo（Python 模拟器） |
