```
任意 Linux 设备 (~512MB 内存, 0 磁盘)
  │
  ├─ python -m edge config set-node http://<NODE_IP>:48080
  ├─ python -m edge enroll       → 向 iot-node 注册本机
  ├─ python -m edge run           → 订阅 EMQX MQTT 任务指令
  │
  ▼
┌───────────────────────────────────────────┐
│              EMQX MQTT Broker              │
│  任务 Topic: easyaiot/edge/{nodeId}/task   │
└──────────────────┬────────────────────────┘
                   │
                   ▼
┌───────────────────────────────────────────┐
│        EDGE 运行时 (workload_runner)       │
│  拉流 → YOLO 推理 → 结果上报              │
│  不落本地业务盘 / 不直传 MinIO            │
│  告警证据通过 Ceph 热度缓存自动汇聚上云    │
```
