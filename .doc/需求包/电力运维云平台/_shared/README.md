## 追踪与维护规则

- PRD → Spec → ADR → TD → 任务 → 测试/验收的关系只登记入口，不复制字段、API、表结构或测试正文。
- 共享 ADR 不强行归属于单一 PRD；需求包中使用“主责”或“关联”标识。
- Planned / 尚未创建的 Spec 只写纯文本，不创建死链接；原文一经形成即可登记并显式标注状态，批准与冻结仍以专项评审记录为准。
- 每次评审或续作时以当前双基线重新核对，并保留 OPEN 门禁；本页日期快照不是批准或完成证明。
